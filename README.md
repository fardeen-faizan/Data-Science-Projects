# Laptop Data Cleaning using Pandas

## Project Overview

This project demonstrates basic data cleaning techniques using Python and Pandas on a laptop dataset.

The original dataset contained duplicate records, inconsistent data types, unnecessary text in numeric columns, and inconsistent column names.

The cleaned dataset is included along with the Jupyter Notebook used for the cleaning process.

---

## Files

- Laptop_Data.xlsx (Original dataset)
- Cleaned_Laptop_Data.xlsx (Cleaned dataset)
- Laptop_Data_Cleaning.ipynb (Cleaning notebook)

---

## Data Cleaning Steps

- Removed duplicate rows
- Renamed incorrect column names
- Converted numeric columns to appropriate data types
- Removed unnecessary units and symbols
- Standardized column names
- Checked for missing values
